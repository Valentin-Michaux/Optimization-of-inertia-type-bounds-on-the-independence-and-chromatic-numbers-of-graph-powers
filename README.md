# Optimization-of-inertia-type-bounds-on-the-independence-and-chromatic-numbers-of-graph-powers
Implemented codes for the experimental results for the paper "Optimization and complexity of inertia-type bounds on the independence and chromatic numbers of graph powers" by Aida Abiad, Stan van Hoesel, and Valentin Michaux.

There are 4 different codes running the old and new MILPs for the inertia-type bound for the k-independence number and the second inertia-type bound for the distance-k chromatic number. These codes run using sage which is not available through Windows

Additionally, graph_list.txt contains all the graphs from the table in the paper
